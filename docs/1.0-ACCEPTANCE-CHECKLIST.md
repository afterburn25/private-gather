# 1.0 Acceptance Checklist

## Fresh install
- [ ] Server requirements page passes.
- [ ] The application root renders the installer inline before installation without redirecting to domain-root `/install/`.
- [ ] Installer creates/uses the selected database.
- [ ] Complete schema imports without error.
- [ ] First platform administrator can sign in.
- [ ] Installation lock/receipt are written outside public content.
- [ ] `/install` is deleted or disabled after success.
- [ ] The application root loads the installed site afterward and remains mounted at the configured root/subdirectory.

## Tenant/domain
- [ ] Create club, organizer, and private-host tenants.
- [ ] Platform subdomain resolves the correct tenant.
- [ ] Unknown hostname fails closed.
- [ ] Custom-domain ownership TXT check works.
- [ ] Primary-domain selection works.
- [ ] Custom-domain TLS/routing is configured at the chosen edge provider.

## Member/security
- [ ] Adult member can register and sign in.
- [ ] Under-18 registration is rejected.
- [ ] Terms/privacy consent is recorded.
- [ ] Password reset works after mail configuration.
- [ ] Email verification works after mail configuration.
- [ ] Optional TOTP 2FA can be enabled/recovered/disabled.
- [ ] Block/report/privacy controls behave as expected.

## CMS/branding
- [ ] Platform administrator can edit central marketplace text/images and optional homepage sections.
- [ ] Tenant can edit site settings/navigation/branding.
- [ ] Tenant can create/edit CMS pages and blocks.
- [ ] Safe placeholders render expected tenant/event/site data.
- [ ] Unknown placeholders remain non-executable.
- [ ] Private media requires authorization.

## Events/commerce
- [ ] Organizer creates/publishes/duplicates an event.
- [ ] Exact private location is not exposed publicly.
- [ ] RSVP approval/waitlist/questions work.
- [ ] Private/invite-only events reject direct self-RSVP and require an accepted invitation token.
- [ ] Ticket types and free checkout issue tickets.
- [ ] Paid/manual order remains pending until confirmed.
- [ ] Confirming paid order issues tickets once only.
- [ ] Door check-in rejects duplicate use.

## Admin/moderation
- [ ] Platform admin can manage users/tenants/plans.
- [ ] Reports can be triaged/resolved.
- [ ] System Health returns expected status.
- [ ] Audit/upgrade records are created.

## Upgrade
- [ ] 0.1.2 test copy upgrades sequentially through 1.0.0.
- [ ] Wrong-version ZIP is rejected.
- [ ] Tampered payload hash is rejected.
- [ ] Protected path is rejected.
- [ ] Backup/log can be retrieved after upgrade.
- [ ] Site exits maintenance mode after success/failure handling.
